# AI 生图加载动效预览

这是一个纯 HTML/CSS 的 AI 生图加载动效 Demo。

> 如果你看到 `127.0.0.1 拒绝了我们的连接请求` / `ERR_CONNECTION_REFUSED`，说明本地预览服务没有启动，或端口没有暴露。请先运行下面的启动命令，再打开预览地址。

## 快速预览

### 推荐方式：启动预览服务

在项目根目录运行：

```bash
npm run dev
```

然后访问：

```text
http://127.0.0.1:3000/
```

如果是在容器、云 IDE 或在线工作区里预览，请使用平台提供的端口预览入口打开 **3000** 端口。项目启动脚本已经绑定到 `0.0.0.0`，便于外部预览面板访问。

### 备选方式：直接打开文件

也可以双击或在浏览器中打开：

```text
index.html
```

## 页面内容

- 深色玻璃拟态卡片
- AI 生图预览占位图
- 扫描光效、漂浮像素、闪光粒子
- 旋转 AI 光环
- 流动进度条
- `prefers-reduced-motion` 动效降级支持
